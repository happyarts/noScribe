# Optional Voxtral transcription engine (Apple Silicon only).
# Install on top of requirements_macOS_arm64.txt to enable the "voxtral-mini"
# and "voxtral-small" models in the transcription backend:
#
#   pip install -r environments/requirements_voxtral_macOS_arm64.txt
#
# Transcription runs on the Apple Silicon GPU via MLX. When a timestamped
# output is requested, word timestamps are recovered with CTC forced alignment
# (transformers + torchaudio) against a German wav2vec2 model.
#
# mlx-voxtral is pinned because the engine was validated against one version,
# not because upstream is dead: it went a year without a release, then in
# 2026-08 relicensed to MIT and merged a fix. mlx and mlx-lm
# are pinned too because voxtral_engine drives decoding through mlx_lm internals
# (generate_step + a small model adapter); a newer mlx-lm could change that API
# or break the frozen mlx-voxtral. These are the versions the engine and its
# byte-identity tests were validated against -- bump them deliberately, together.
mlx==0.32.0
mlx-lm==0.31.3
# 0.0.5 carries the stop-token fix (32000 is the text token " Capital", not a
# pad token) and is the first release under plain MIT -- 0.0.4 and earlier were
# "Personal Use Only", which GPL-3.0 could not have carried.
mlx-voxtral==0.0.5
# transformers 5 is what the engine was validated against, and mlx-lm 0.31.3
# already requires it -- a lower floor here only allowed an untested 4.x to
# satisfy this file while pip installed 5 anyway.
transformers>=5
torchaudio
soundfile
